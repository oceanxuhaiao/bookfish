# 08 · not_observed 清单与真实宿主验收步骤

本文件的作用：**不要把"没看到"当成"已验证"**。本阶段是"宿主验收准备"，自动化在 jsdom + Node 环境完成，没有在隔离桌面宿主里用鼠标点过，因此任务书第 9 节列出的项目全部标记 `not_observed`。

## B. 已知限制（设计取舍，不是缺陷）

| # | 限制 | 说明 |
| --- | --- | --- |
| B1 | 历史明细仍只保留最近 300 条（视图 50 条） | 本轮只新增累计计数与截断审计；**不等于完整逐本历史**，页面已明示。导出方案见 `04`，本轮不实施 |
| B2 | 预算口径需审核确认 | `workspaceBytes = 1536 MiB` 是把隐含共存占用显式封顶，未提高任何已发布上限；若审核认定为预算变更，请退回本轮（见 `00` / `03`） |
| B3 | rename 失败回退时的瞬时单条目副本 | `copyThenUnlink` 会让单个 ≤100 MiB 条目瞬时多一份，源随即删除；`peakBytes` 实测点在 rename 之前，不含这一瞬时字节。正常同盘路径不触发 |
| B4 | 前端 `fileDigest()` 只对 ≤64 MiB 计算期望摘要 | 更大文件留空，由服务端 `sha256File()` 计算；声明值永远不是身份依据 |
| B5 | 计划页用按钮排序，不是拖动排序 | v1.1 已声明，本轮未实现拖动 |
| B6 | 停止当前书必须有可读的下一本 | 没有就禁用并解释；替代路径是"移出计划，继续读这本" |
| B7 | `selection.queue` 是只读投影 | 任何直接写 `draft.queue` 的旧代码会失效（仓库内已迁移） |
| B8 | `check:ssm` 保持 2 REVIEW | `library.ts` / `world.ts` 在 review 清单里，任何改动都触发；未自行放行 |
| B9 | 批次记录最多 20 条 | `trimBatches`；清理只删记录不删书 |

## C. 集中式真实宿主验收步骤（任务书第 9 节）

**前置原则**：使用独立隔离桌面宿主与独立 `data` 目录；**绝不指向正式用户数据目录**；先备份隔离目录；验收构建的侧载与回滚参照 v1.1 的 `06-数据安全与回滚报告.md`。全部步骤一次性准备、一次性观察，**不要求用户逐章重复提供阅读证明**——以宿主状态、面板显示与库快照为证据。

| 步 | 操作 | 观察点 | 判定标准 |
| --- | --- | --- | --- |
| 0 | 侧载 v1.2 验收构建到隔离宿主，重启，确认 `GET /api/webui/manifest` 下发的 `world:bookfish` client.js 是本轮产物 | manifest 路径/哈希 | 加载的是验收构建 |
| 1 | 准备素材：3 本小 `.txt`、`系列/` 文件夹（2 本）、1 个 ZIP（含 2 本）、1 个与某 txt **同大小但内容不同**的文件 | 素材字节数与 SHA-256 先记录 | 可复现 |
| 2 | **真实文件多选**：在书架批量导入里一次选 3 本 txt | 批次出现 3 个条目、并发 2、逐本完成、书架 +3 | 全部 completed，无重复、无丢失 |
| 3 | **真实文件夹选择**：选 `系列/` | 相对路径保留、自动建议系列、 unsupported 项（如 cover.jpg）被拒 | 2 本入库，系列名正确 |
| 4 | **真实 ZIP 选择**：选 ZIP 并上传完成 | 面板显示 ZIP 四态、`peakBytes` 非 0、解压后 ZIP 被删、条目就位 | `state = extracted`，无残留解压目录 |
| 5 | **ZIP 中断恢复**：ZIP 上传到一半关闭宿主（或硬杀），重启 | 面板出现"重新选择 ZIP"，同 `batchId`；重选同一 ZIP 后完成 | 不重复导入已成功书籍 |
| 6 | **重新选择文件**：把某条目置为 `needs_reselect`，先选同大小不同内容文件，再选原文件 | 前者被拒并提示摘要不符；后者恢复成功，`itemId` 与顺序不变 | 错误文件不进入 ImportJob |
| 7 | **计划页展示**：把 3 本加入计划，选中第 1 本；然后把它"移出计划，继续读这本" | 显示"正在读 · 计划外" + 真实进度 + 加回按钮；计划总数不变、下一本顺序不变 | 当前书不消失 |
| 8 | **keepReading 与错误提示**：在无下一本时点"停止读这本，改读下一本"；再制造一次排序/持久化失败 | stop 禁用并解释；错误条显示人话原因，不静默 | 两种拒绝都有明确反馈 |
| 9 | **三本书自动连续阅读**：恢复计划，让宿主按计划连读 3 本 | 逐本完读归档、自动切下一本、累计读完数递增；暂停/暂缓时归档但暂不切换 | 归档 + 交接与自动化用例一致 |
| 10 | **历史统计**：检查"累计读完"、跳过/移出计数、历史保留说明 | 计数不随 300 条窗口收缩；系列解散后历史仍显示系列名 | 与 `plan.stats` 一致 |
| 11 | 收尾：记录隔离 `data` 快照、面板截图、宿主日志；需要时把 symlink 指回旧版并重启回滚 | 证据归档 | 正式数据零改动 |

**如果宿主不可用**：以上 2–10 全部保持 `not_observed`，本阶段仅交付自动化证据，不声称真机验收通过。
