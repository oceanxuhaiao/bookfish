# 多书导入与阅读顺序 UI 调整 · 2026-11-26

## 已确认方案与实现

用户接受统一推荐书籍入口、导入分步、文案和视觉收敛，并明确：正在读为主体，阅读顺序仅以小按钮进入抽屉，不保留独立阅读计划页面。本次在既有 bookfish-reading-plan 开发目录实现。

- 正在读保留封面、进度、心情、阅读感想与现有操作；次级按钮显示后续本数。移除宿主与内部导航的 plan 页；原计划接口与存储保持兼容。
- 阅读顺序通过宿主 drawer 展示当前书、等待项、排序、按顺序继续开关。当前书不重复进入可重排列表。后续书支持拖动、上下移动、设为下一本；不常用操作进入更多菜单。系列管理和统计默认折叠，整组移动先展示结果供确认。
- 书架统一“推荐书籍”入口，本地导入支持单本、多本、文件夹和 ZIP，在线查找保留链接与书名作者渠道。原批量导入折叠入口与永久 hidden 根节点已移除。
- 导入按选择文件、确认书目、结果呈现；预览可取消勾选，导入时调用既有取消条目接口；结果再次显式选择要加入阅读顺序的书籍。默认不选、不自动开读；分组需显式确认。
- 失败与不支持文件按详细报告保留；ZIP 拒绝态不提供无效开始按钮。导入记录可恢复，后台进行中的批次在书架显示进度入口。
- 移除书架上重复的旧排队投影，避免把用户入队书显示成“她的自选书”。当前无书但书架非空时不再声称书架为空。页面切换同步宿主路由。
- 浏览器资源采用内容摘要命名，避免宿主 immutable 缓存继续显示旧界面。
