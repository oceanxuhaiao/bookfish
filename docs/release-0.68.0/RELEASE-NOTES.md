# BookFish 0.68.0 —— 语音朗读（实验）

本版本新增实验性的语音朗读：大肥鱼可以把正在读的小说读给你听，并与原有阅读进度、时间轴、心情与足迹保持一致。

## 新增

- 语音朗读（实验）：开启后按阅读顺序，用小米 MiMo 合成人声朗读已缓存正文；只朗读已缓存段落，不跳读、不改写原文。需要在「配置 → 语音朗读」保存小米 MiMo API Key（当前 TTS 限时免费）。
- 「正在读」页新增阅读模式 / 朗读模式切换（仅在启用语音后出现）；继续读与暂停阅读按模式统一。
- 朗读模式下每完整播放一段，就按原阅读逻辑更新时间轴、最近心情与阅读足迹；不进入会话休息，也不受作息限制。只有原确认机制会推进阅读进度。
- 聊天优先：发消息会立即打断朗读；一轮聊天结束后自动从停下的未读完段落继续。

## 改进

- 配置页改为按类别折叠，避免页面过长。
- 语音设置增加小米 MiMo API Key 获取入口与“限时免费”提示。

## 注意

- 语音走云端小米 MiMo：正文会发送给该服务，不是本地离线朗读。
- KEY 只保存在本机部署 `.env`，配置、日志与模型工具都不会拿到明文。
- 聊天中断、删除 KEY、切书、暂停都会安全停止并保留已完整播放的水位。
