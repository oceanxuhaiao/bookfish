## 本阶段做了什么（产品视角）

- **批量导入**：一次选多本 / 选整个文件夹 / 选一个 ZIP → 先出预览（数量、书名、系列建议、疑似重复、不支持文件、预计占用）→ 再开始导入 → 后台按状态机逐本推进，单本可取消、可重试，进程中断后能恢复。
- **统一阅读计划**：全扩展只有一份计划，顺序可改、可置顶、可插到下一本、可移到最后、可整组（系列）移动。当前在读书默认锁定，普通重排抢不走它。
- **五种结局严格区分**：移除计划 / 暂时跳过 / 停止当前阅读 / 放弃自选书 / 真正完读。只有最后一种是完读，其余都不改完读门槛。
- **调度**：没有第二套调度器。`PlanCoordinator` 只在既有 scheduler 的空闲交接点决定"读哪本"，进度仍由 `readNext` / `finish` / `finishMany` 推进。
