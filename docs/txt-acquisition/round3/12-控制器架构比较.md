# BookFish 浏览器安全控制器：WFP 与 VM 技术选型报告

状态：设计 PARTIAL；正式控制器实现、安装与验收均 NOT_TESTED。本轮未启用虚拟化、未安装服务或新增网络规则。技术路线等待产品负责人决定。

## 威胁与信任边界

浏览器页面、下载内容、站点重定向、扩展上传消息都不可信。需限制浏览器 TCP/UDP、IPv4/IPv6、QUIC/WebRTC、DNS/DoH、代理绕过、回环、内网、元数据地址和更新进程；端口、地址、授权来源每跳检查。管理员、内核与虚拟化平台被攻陷不在本模块能够抵御的范围内。普通站点登录只允许用户在独立受控环境完成，不读取日常浏览器 Cookie。

就绪不能来自扩展连接：应由带版本和随机挑战的控制器证明，绑定实例身份、浏览器二进制哈希、网络规则摘要、精确代理/桥接端点、租约期限。World 只在证明有效、代理和桥接健康、网络及来源授权有效时派发；保护丢失立即取消任务并终止浏览器，原件和任务保留恢复线索。此为待实现协议，当前 World 无控制器，保持 controllerReady=false/browserReady=false。

## A：宿主独立浏览器 + WFP

独立 exe/profile、签名清单和专用 provider/sublayer；管理员服务只负责本产品实例规则、校验和进程生命周期，普通代理执行 URL/DNS/固定 socket 检查。精确允许 TCP 到两个本地端点，其他目的/协议默认阻断；浏览器更新进程纳入同一边界。规则应在浏览器启动前原子安装，保护进程崩溃仍保持阻断；不能依赖动态会话退出即删除全部保护。

**共享 DNS 是阻断项。** 上轮日志已实测 Dnscache 可由共享 svchost 代发。AppId 匹配浏览器 exe 无法证明代发请求属于该浏览器；屏蔽整个 Dnscache 会影响全机，违反边界。ETW 事后关联、启动参数、禁用预解析或仅设置代理都不能成为强制归属证明。WFP 的 AppId、服务身份等条件本身也不证明原始 RPC 请求者身份。参见 [WFP 条件定义](https://learn.microsoft.com/en-us/windows/win32/fwp/filtering-condition-identifiers-) 和 [WFP 架构](https://learn.microsoft.com/en-us/windows/win32/fwp/windows-filtering-platform-architecture-overview)。

因此 A 目前没有满足“强制、可验证、不影响其他应用”的完整答案。若继续 A，必须单独论证并实验验证 AppContainer/独立网络 compartment 等边界对所有 DNS API 和浏览器子进程的覆盖；不能把尚未证明的机制写成已解决。任何驱动/管理员组件另行授权、安全审核及签名发布。

## B：独立 VM + 受控代理

浏览器和 Dnscache 均在独立 guest 网络空间。选择专用隔离交换网络；禁止 Default Switch、外部交换机、默认 NAT 和第二张可达公网网卡。guest 只能到精确宿主网关端点；网关只提供受控代理与认证桥接，不转发任意 TCP/IP。没有默认路由仍不足够，必须验证 IPv6、链路本地、宿主所有接口、其他 VM、UDP 和新增网卡均拒绝。DNS 由受控代理解析，guest 向外 DNS 仍须强制阻断。

Hyper-V internal switch 包含宿主连通能力，private switch 仅 VM 互通；两者都需要设计实际代理接入路径，不能默认“internal 等于隔离”。参见 [交换机配置](https://learn.microsoft.com/en-us/windows-server/virtualization/hyper-v/get-started/create-a-virtual-switch-for-hyper-v-virtual-machines)。可使用专用网关 VM 加 private switch，或 internal switch 配精确宿主入站/转发限制；二者均需管理员批准和可重复 canary。桥接不能简单暴露到 0.0.0.0；限定虚拟接口、随机凭据、来源实例、消息大小和租约。禁止共享宿主文件夹/剪贴板/磁盘重定向；下载只经认证分块协议导出到暂存区重新验证。

guest 本机回环仍有攻击面，须只运行所需服务并验证浏览器对其他回环端点不可达。镜像签名/摘要、只读基镜像、可丢弃差分盘、更新后重新验收和可信回滚不可省略。VM 逃逸、配置漂移、网络重新挂接和代理策略错误仍有风险。

## 对照与建议

|指标|A：宿主 WFP|B：独立 VM|
|---|---|---|
|强制网络边界|浏览器进程可控，共享 DNS 未解决|guest 整体边界较清楚，但交换网络/网关必须实证|
|DNS 绕过|当前阻断发布|共享服务留在 guest 内，仍须验证无外部路径|
|安全证据|进程/服务归属复杂|网卡、交换机、网关和 guest canary 可重复|
|安装与日常体验|较轻；需服务安装和来源授权|镜像启动及独立登录更繁琐|
|资源|预计较低，未测量|预计更高，未测量；不编造 CPU/RAM 数字|
|管理员权限|服务、provider/sublayer/规则、更新器|虚拟化功能、交换网络、网关规则、VM 生命周期|
|Windows 兼容|需逐版本 WFP/浏览器测试|客户端需受支持版本、硬件虚拟化和许可|
|更新维护|浏览器 exe 身份变化需先阻断再换规则|浏览器/guest 镜像更新后整体重验|
|崩溃/断电|持久阻断及恢复事务复杂|先关 guest 网络，快照/差分盘恢复仍要验证|
|卸载|只删除产品清单对象，停止浏览器后撤规则|先停止 VM，删自有网卡/规则/镜像；不改其他 VM|
|普通用户|授权来源和独立 profile 登录|授权来源和 VM 内登录；不复用宿主凭据|

建议优先对 B 做下一轮可行性验证，前提是用户接受安装、资源与维护成本。A 不应在 DNS 归属缺口仍存在时进入产品安装阶段。这是工程判断，不是已完成的安全认证。微软 [Hyper-V 概览](https://learn.microsoft.com/en-us/windows-server/virtualization/hyper-v/overview) 列出客户端版本范围；实际设备还需按 [硬件要求](https://learn.microsoft.com/en-us/windows-server/virtualization/hyper-v/host-hardware-requirements) 和许可逐机确认。本轮不执行启用检查以外的系统修改。

## 状态机（待实现）

|状态|进入/退出条件|允许动作、失败动作与规则|派发|管理员|
|---|---|---|---|---|
|uninstalled|无有效安装；批准安装后进入 installing|只显示状态/设计；不启动浏览器，无产品规则|否|查询否，安装是|
|installing|安装事务开始；全量核验成功进 protected|先建立阻断再装组件；中断转 recovery_required，禁止启动|否|是|
|protected|二进制/规则/端点证明有效；浏览器及扩展健康后进 browser_ready|允许启动独立浏览器，规则持续阻断其他出站|否|日常否，修复是|
|browser_ready|全部健康且授权有效；任一失效进 fail_closed|只派发租约内授权任务，持续健康检查和证明续期|是|否|
|fail_closed|保护/代理/桥接/权限失效；重验成功回 protected|停止派发、撤租约、终止浏览器；保留阻断及原件|否|视修复项|
|recovery_required|规则/清单不完整、安装卸载中断、版本不明|仅诊断/授权修复；不得仅凭旧 ready 缓存恢复|否|规则修复是|
|upgrading|停任务和浏览器后进入；新版本全验回 protected|保留阻断，原子切换清单；失败回可信旧版本并重验，否则 recovery_required|否|受控更新是|
|uninstalling|用户明确卸载；进程退出且自有对象清除回 uninstalled|先停止浏览器，再按清单删除；中断 recovery_required，不能提前撤防|否|是|

## 故障验收清单（全部待实际控制器实现后执行）

|故障|要求|
|---|---|
|服务崩溃|规则不消失，浏览器不能自行获得公网；World 失联失败关闭|
|代理崩溃|连接失败，禁止直连回退；已上传原件不丢失|
|桥接崩溃|旧 token/lease/attempt 不可重放，新连接重新授权|
|浏览器崩溃|终止任务租约，重启只能在保护核验后|
|系统重启/断电|默认不启动浏览器；重查规则、清单和网络再恢复|
|浏览器更新|新二进制先隔离，更新进程也受限制；旧路径规则不等于新版本证明|
|安装中断/规则部分写入|事务回滚或进入 recovery_required；禁止先启动后补规则|
|卸载中断|浏览器保持停止；清单可继续，不能影响其他产品|
|manifest 损坏|拒绝就绪，保留现场和诊断，不能重建全允许默认值|
|版本回滚|签名版本匹配配置/协议，重新执行全部 canary，旧 ready 失效|

## 下一阶段需明确批准的项目

选择 A 或 B；允许安装哪些管理员组件及其路径/账户权限；是否启用 Hyper-V 和重启；允许创建的交换机/网卡/精确网络规则；镜像来源/许可/磁盘资源；故障恢复和卸载操作范围。默认不批准修改系统 DNS、防火墙全局默认策略、安装根证书或访问日常浏览器凭据。

无论选择哪条路线，先交付具体安装/卸载和恢复清单、威胁模型及 canary 计划供审核，再请求系统变更。当前代码维持失败关闭，不合并 main、不部署生产。
