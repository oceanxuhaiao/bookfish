## 样本与可复现方法

基础入口为 `scripts/round4-final-host.mts <已安装app路径> --authorized-elevated --hold`。必须在候选 worktree 运行；唯一数据目录自动生成，来源由源码而非生产配置提供。脚本实际装载 Core、完成 API 断言并暂时保持运行，测试结束写自有 stop.request 正常退出。完整执行记录见 `evidence/host/results.json`。

`scripts/round4-final-host-identity.mts` 只读取当前脚本生成的 `_verify/host-final-current.json` 中独立实例地址与路径。在实际 Core 中停用 BookFish 后，使用真实 Library/TxtAcquisition 和合成正文创建 generic/身份不匹配的持久化恢复夹具，然后重新启用实际 World，调用其原有公开 API 验证。没有修改生产 World、新增常驻工具或绕过安全 Guard。夹具准备与真实宿主恢复必须分开认定；不能据此宣称完成真实传输链路。

原件来自重复的合成短句，不含真实用户小说全文。测试本身与恢复操作不代表她真实阅读；所有新书进度保持零。私有完整数据目录留作本地复现，不打包 home、Memory、模型配置或书籍原始存储。
