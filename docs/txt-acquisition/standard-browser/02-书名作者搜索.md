# 书名/作者搜索与可选资源页入口

用户希望配置好后直接按书名或作者找书，不先查资源页地址。原入口只做指定页面的TXT链接发现，欠缺搜索步骤；本次新增搜索，而非要求用户继续填网址。

实现冻结347717bd1ff221b351f3e43a86e6231e47e38af2；实机权限错误提示补正54e8786（完整提交见git log与安装证据）。比较起点5e95dab。

主流程：书名或作者至少一个 → Bing网页搜索 → 最多12条作品/来源线索 → 确认可修改的目标书名 → 发现TXT/Markdown候选 → 核对文件并导入。原资源页表单折叠为可选手动入口。只填作者不将作者充当书名。搜索结果的标题、摘要、建议书名均非已验证身份，不代替文件实际metadata；不会直接自动入架。

复用现有浏览器模式、扩展桥接、URL检查、来源授权、租约和下载校验；模型原TXT工具增加search action，不新增工具或自动打开自主找书。搜索无书架写入、获取任务或阅读承诺；最多两条并发，传输30秒超时，权限撤销/关闭World中止。搜索结果如为直接TXT链接，只建立候选，尚未下载。没有安装系统组件、修改浏览器个人配置或读取Cookie。

## 来源授权与成本

搜索词会发送给Bing，界面明确说明。首次需在扩展授权 https://cn.bing.com；打开搜索结果的新网站也须来源权限。用户不用自行寻找每本书的资源页URL，产品从搜索结果提供该URL；来源授权仍保留，不偷偷授予所有网站权限。遇到验证码停止，不绕过访问控制。不保证所有关键词都能找到可下载文件，失败可改词或使用可选手动入口。

查询拼接、HTML结果解析、去重与显示均本地确定性处理，不新增模型调用。一次显式搜索新增一个浏览器页面请求，换来自动查找资源页的产品价值；没有声称Token节省。模型工具动作/按需说明略有增加，未测量Token差值，不更改真实阅读、记忆与已读语义。
