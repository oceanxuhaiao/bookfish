# 普通浏览器模式：实现与验收

## 授权与行为

2026-11-22 用户明确将手动和模型自主浏览都改为“放宽限制＋建议增强保护”。这是对旧控制器必需条件的产品策略修订，不是宣称 WFP/DNS 隔离问题已解决。

默认增强保护，缺少控制器继续拒绝；用户可在书架的浏览器 TXT 获取向导选择普通模式，明确确认同时适用于模型自主浏览。确认后不强制要求安全组件或独立浏览器。普通模式不会将 controllerReady 或 isolationVerified 改成 true。自主找书总开关不自动开启，模型工具不能代替用户保存模式确认。

保留联网权限、扩展配对、逐来源授权、URL/下载校验、4MiB 分块、租约及 Attempt、大小/哈希、重试和取消规则。切换模式或撤销确认中断在途任务，旧租约上传被拒绝。普通模式下网页的网络请求不具备已验证的强制隔离，可能使用浏览器已有会话。

当前“一键配置”能启用必要设置并启动本机桥接，不能自动安装扩展或配对，界面明确引导到配置页。推荐安全组件及独立浏览器，增强模式的正式控制器仍未实现。未修改系统网络、浏览器个人配置或账户凭据。

## 验证口径

- 单元/协议：普通模式无 Guard 或 controller stub，模型自主 origin 经真实获取服务完成桥接下载、入架，confirmedChars=0；增强模式的 Guard 是明确的测试夹具。
- 故障：确认缺失、网络权限缺失、端口失败回退、并发撤销不被恢复、旧上传租约拒绝、用户设置面板切回增强模式。
- 真实宿主：安装中的 Coopanion Core，独立合成数据、无模型凭据；公开面板 API 验证普通模式确认、连接就绪、World 重启保留及撤销；桥接 hello 是本机协议客户端，不冒充真实浏览器或权限弹窗验收。
- 日常实例更新须先停写和新备份，在私有副本比较旧/新书架、已读边界和历史，再切换独立安装目录。不会替用户接受普通模式或打开自主找书。

不新增模型调用、常驻上下文或阅读语义，微小模式字段不宣称 Token 节省。

## 保留边界

正式扩展安装/更新/权限对话和真实浏览器自动派发未在本轮验收；完整 verify:world 的来源身份问题未由此修复。SSM 独立审核不自动接受。不 push、不合并 main、不正式发布。
