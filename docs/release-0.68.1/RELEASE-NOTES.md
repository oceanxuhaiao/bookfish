# BookFish 0.68.1 —— 阅读模式与朗读模式分开

0.68.1 是语音朗读的补丁版本，修正模式切换后普通阅读被语音门控拦住的问题。

## 修复

- 阅读/朗读模式改为保存在宿主配置里（`voiceReadingMode`）。切到阅读模式后，普通阅读不再等待语音播放进度，“继续读”可以正常发起；朗读模式才套用语音门控。模式在刷新页面、重启宿主后保持。
- 朗读模式下，正在朗读（开始中、播放中、等待后续正文）时“继续朗读”不可点；没在朗读时“暂停朗读”不可点。切回阅读模式恢复“暂停阅读”，由原阅读状态控制。

## 不变

- 语音启用开关、KEY 存储方式、MiMo 合成与安全边界不变；已有的配置和 KEY 不需要重新填写。
- 阅读进度、时间轴、心情与阅读足迹的确认机制不变。

## 验证

- 两套 TypeScript 类型检查通过；全量 147 个测试文件、1536 条（1535 通过 + 1 跳过）。
- 正式宿主验收：设为阅读模式后 `read_now` 返回 `accepted:true`，实际阅读从第 256 段推进到第 258 段；重启后模式仍为阅读模式。
