## 看书吧！大肥鱼 0.63.1

本版汇总 0.63.0 的改进与 Issue #2 写锁修复，不包含开发中的浏览器 TXT 获取功能。

- 独立 SQLite 事务写锁：修复异常退出残留锁、PID 被无关进程复用后 World 永久无法启用的问题。
- 旧 JSON 锁核验真实进程创建时间；无法确认身份时保守拒绝并提供中文恢复步骤。
- 关闭业务资源后才释放写锁；初始化失败清理、重复关闭与启停竞争保护。
- 包含此前 TXT 导入孤立坏字节修复、长连载候选与目录修复、“从某一章开始读”。

验证：683 项测试、双端 TypeScript、官方扩展检查通过；Windows 10 + Coopanion 0.2.23 实机开关/重启，以及 Core 强杀后自动恢复通过。原 11 本书、1,496 条确认记录、762 条足迹与正文哈希保持完整。

升级前请退出所有旧实例并备份书库。不要运行中删除锁数据库。沿用 0.63.0 的兼容限制：设置过阅读起点的书不能直接用 0.62.1 及更早版本打开。
