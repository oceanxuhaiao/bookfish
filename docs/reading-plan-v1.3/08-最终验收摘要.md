## 4. 需要审核方裁定的两处（不是缺陷，是口径）

1. **产品预算是否算变更**：v1.3 未改动任何已发布上限（100 MiB 单本 / 100 项 / 1 GiB 暂存 / 512 MiB ZIP / 并发 2）。变化的是"上限**如何被实测**"——从"一层目录估算"变成"递归真实占用"，因此实际可用空间**收紧**而非放宽。若审核认为口径变化本身需报批，请退回本轮。
