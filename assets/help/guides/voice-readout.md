# 语音朗读（实验）

让大肥鱼把正在读的小说读给你听，而不是只在心里默读。这是实验功能，默认关闭。

## 开始之前

1. 到小米 MiMo 控制台获取 API Key：<https://platform.xiaomimimo.com/console/api-keys>（当前小米 MiMo 语音服务限时免费）。
2. 打开「配置 → 语音朗读（实验）」，启用语音朗读并保存 KEY。KEY 只保存在本机部署的 `.env` 里，配置、日志和模型工具都拿不到明文。
3. 到「正在读」页点击“继续读”。如果这是第一次，会从当前位置开始朗读已缓存的正文。

## 阅读模式与朗读模式

- 「正在读」页的切换按钮只在**启用语音朗读后**出现，用来在阅读模式和朗读模式之间切换，且不会改动配置里的启用开关。
- 阅读模式：继续读发起一次普通阅读，暂停阅读暂停阅读节奏。
- 朗读模式：继续读开始或继续朗读，暂停阅读停止朗读。

## 进度、时间轴与心情

- 朗读和阅读共用同一套阅读进度：每完整朗读完一段，才会推进语音水位；未读完的段落不会被记为读完。
- 朗读模式下，每完整播放一段，会按原有阅读逻辑更新时间轴、最近心情与[阅读足迹](help:reading-trail)。这里不进入会话休息，也不看作息时间。
- 只有原确认机制会推进阅读进度；切回阅读模式后恢复原来的阅读节奏与休息。

## 聊天优先与恢复

- 你在聊天时发消息会立即打断朗读；这一轮聊天结束前不会自动继续。
- 一轮聊天结束后，她会自动从刚才停下的未读完段落继续朗读；也可以在配置里关掉语音，恢复默读。
- 聊天中切换书籍、暂停阅读或删除 KEY，都会安全停止朗读并保留已完整播放的水位。

## 隐私与费用

- 语音走云端小米 MiMo：已缓存的小说正文会发送给该服务，不是本地离线朗读。
- 需要你自己的 API Key；KEY 不会出现在配置、日志、截图或模型工具里。
- 关闭语音朗读后会立即恢复原来的默读，不再把正文发给 MiMo。
