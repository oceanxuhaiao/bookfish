# 暂停与继续

暂停会让她停止自主阅读，并取消尚未完成的阅读任务；继续后会重新获得正常的阅读机会，但不会补读暂停期间的时间。

## 怎么使用

1. 在「正在读」点「暂停阅读」。
2. 想恢复时点「继续读」；它会恢复阅读并发起一次请求。
3. 如果她正在休息，可以先点「结束休息」，再继续读。
4. 如果处在睡觉或用餐时间，需要等作息结束，或到「配置」关闭真实作息。

## 需要注意

- 暂停不是关闭扩展。暂停只影响阅读调度，书架、足迹和讨论仍然可用。
- 暂停会取消在途任务；之后重新取正文，不会把取消的那段算作已读。
- 已经确认的进度和足迹不会因为暂停而丢失。
- 继续读不会追补离线时间，也不会自动连续读完整本。

## 进一步了解

「继续读」是一次明确的人类请求，不要求等待自主阅读的字速计时；但它仍受作息、暂停和正文可用性的限制。
