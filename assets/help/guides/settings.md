# 配置项怎么找

阅读、分享、作息和数据管理分散在几个明确的位置。这里帮你快速找到，不需要读完整个使用手册。

## 怎么使用

1. 打开宿主里的「配置」页，进入本扩展的「阅读配置」。
2. 「阅读与分享」放常用项：自主阅读、找书、阅读速度、每轮时长、章节目标、分享间隔、安静时段。
3. 展开「高级设置」可以看到完读读后感、联网开关、阅读方式和全文保存位置。
4. 「小说获取引擎」卡片负责运行时安装、导入、更新和卸载。
5. 备份、恢复和分享历史归档在「书架」→「书架数据管理」。

## 需要注意

- 改完要保存；有未保存修改时，底部会提示。打开帮助不会提交或丢弃这些修改。
- 大多数阅读设置保存后下一次调度生效；全文保存位置和部分运行时设置需要下次启动或重新加载扩展。
- 配置项旁的「?」会直接打开对应说明，不会触发阅读、下载或保存。
- 阅读设置不会绕过暂停、作息或正文完整性校验。

## 进一步了解

想了解每项具体影响，可以点对应行的「?」，或查看[阅读速度与限制](help:reading-pace)、[备份与恢复](help:backup-restore)。
