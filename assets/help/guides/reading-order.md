# 阅读顺序

大肥鱼同一时间只读一本书，但可以事先排好“下一本读什么”。这份顺序只有一条，归你管：她不会自己插队、改序，也不会把排在后面的书偷偷换掉。

## 怎么使用

1. 打开「正在读」，在书的下面点「阅读顺序 · 后续 N 本」；还没有排后续书时，按钮显示「安排接下来读什么」。
2. 抽屉最上面是当前在读的书，下面是等待的书，标题旁显示「等待阅读 N 本」。
3. 调整后面的书：
   - 按住每行左侧的拖动手柄可以拖动排序；
   - 也可以点「···」用「上移一位」「下移一位」「移到最后」或「设为下一本」；
   - 「暂时跳过」只是这次不读，进度和手账都保留，之后还能再加回来；「移出阅读顺序」才是把它从清单里拿掉。
4. 「读完后按顺序继续：已开启」时，她读完一本并满足条件（没有暂停、不在作息休息、没有待写的读后感）后会自动改读下一本可读的书；自动阅读开着、而她当前没有在读的书时，也会从顺序第一本开始。
5. 关掉这个开关只会停止“自动接着读”，清单本身不变。
6. 导入完成后，也可以在结果页点「选择书籍加入阅读顺序」一次加多本；在书籍详情里还能单本加入。

## 需要注意

- 顺序只决定“接下来读哪本”，不改变正文、阅读进度、足迹、读后感或故事记忆；重排不等于重读、跳读或清空进度。
- 当前在读的这本不会被普通排序挤走；要让它离开顺序，得在「更多操作」里明确选择「移出阅读顺序，继续读这本」。
- 「停止读这本，改读下一本」会把它移到“已停止”，不算读完、不删书；没有其他可读的书时这个按钮不可用，并会说明原因。
- 已读完、连载已追平、正文中断或原件已被删除的书，不会被当成“还能接着读”的目标。
- 系列分组只是整理方式，不另排一套顺序；整组移动前会先显示移动结果让你确认。
