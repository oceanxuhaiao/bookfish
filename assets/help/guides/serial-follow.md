# 连载追更

把一本还在更新的网络小说作为连载条目，之后只追加新章，不清空已经读过的进度。这是实验功能。

## 怎么使用

1. 打开「书架」→「＋ 推荐书籍」→「在线找书」→「链接获取」或「书名或作者获取」。
2. 在「作为连载追更」里填入目录链接，点「读取完整目录」。
3. 核对来源、连载状态和章数，确认后点「建立连载追更」。
4. 之后可以在书籍详情的「连载追更」里检查更新，或开启自动检查。

## 需要注意

- 追平当前目录只表示读到目前可读的末尾，不是全书完读，也不会解除「自选书未读完」的承诺。
- 目录只接受严格尾部追加；旧章身份或顺序变化会停止自动同步并保留已读正文。
- 来源用途授权未确认时，只在本机缓存阅读，不宣称正版接入。
- 从备份恢复后，连载订阅默认暂停；确认来源可用后再手动恢复。

## 进一步了解

连载正文仍逐章通过完整性校验；缺章、占位页或分页残留会阻止该批提交，不会跳过缺章继续往后读。
