# 阅读足迹

阅读足迹按现实时间展示她读到哪里、留下了什么感想，以及她当时自报的心情。它不是实时心理监测，也不补造没有记录的内容。

## 怎么使用

1. 打开「阅读足迹」。
2. 顶部可以切到「全部书籍」或某一本书；切换查看不会改变她正在读的书。
3. 用「排序」切换最新在前 / 最早在前，用「每页」选择 5、10、20、50 条；「上一页」「下一页」「回到最新」按当前排序翻页。
4. 在「搜索足迹」里输入关键词，可以跨书或只在当前书里找记录；空格分隔多个词表示同时包含。
5. 每一条显示确认时间、一段剧情摘要和「🐟 大肥鱼当时的阅读心情」。
6. 点「展开剧情摘要」看完整回执；点「聊聊这一段」从这条记录发起讨论。

## 新足迹提醒

打开页面时，如果她在别处写下了新足迹，顶部会出现「大肥鱼新增了 N 条足迹」。

- 点「查看新增」先看这一批新增，不会把历史列表翻走。
- 如果你正停在最新一页（最新在前第 1 页，或最早在前最后一页），不会出现提醒：那页本来就包含最新记录。翻到更早的页面时才会提示。
- 点「整体收起」后提醒消失；没展开或没收起时不会推进提醒位置。
- 一次新增超过 50 条时，预览只展示 50 条，并明确写“显示 50 条”，不会声称全部已展示。

## 搜索说明

- 搜索范围：触发情节、感想、当时的判断与理由、心情标签、人物名/别名、她当时的问题。
- 不搜索原文引文；要看原文请点「查看原文依据与理由」。
- 搜索不区分大小写；清空输入就回到普通列表。搜索词只在这次查看里有效，不会写进浏览位置。
- 搜索结果里继续按当前排序和每页数量翻页。

## 需要注意

- 心情是她在那个任务里自报的标签，不是系统根据剧情推算的。
- 旧记录没有时间或心情时会明确标为未记录，不用后来的记录补造。
- 摘要来自当次理解回执；没有额外调用模型重写。
- 休息记录和阅读记录分开显示，休息不会被写成读书感想。
- 从某条记录发起讨论时，用的是那条记录所属的书，不会因为当前正在读另一本书而换了书名。

## 进一步了解

「查看原文依据与理由」会加载这条记录对应的原文片段和当时写下的解释。修订会追加为新记录，旧记录仍保留。相关功能见[和她聊剧情](help:discuss)。
