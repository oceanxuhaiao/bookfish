# 阅读足迹

阅读足迹按现实时间展示她读到哪里、留下了什么感想，以及她当时自报的心情。它不是实时心理监测，也不补造没有记录的内容。

## 怎么使用

1. 打开「阅读足迹」。
2. 用顶部选择器切换要查看的书；切换查看不会改变她正在读的书。
3. 每一条显示确认时间、一段剧情摘要和「🐟 大肥鱼当时的阅读心情」。
4. 点「展开剧情摘要」看完整回执。
5. 点「聊聊这一段」从这条记录发起讨论。

## 需要注意

- 心情是她在那个任务里自报的标签，不是系统根据剧情推算的。
- 旧记录没有时间或心情时会明确标为未记录，不用后来的记录补造。
- 摘要来自当次理解回执；没有额外调用模型重写。
- 休息记录和阅读记录分开显示，休息不会被写成读书感想。

## 进一步了解

「查看原文依据与理由」会加载这条记录对应的原文片段和当时写下的解释。修订会追加为新记录，旧记录仍保留。
