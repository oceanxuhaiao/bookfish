# 作息与休息

大肥鱼有自己的作息。吃饭、睡觉和读书间歇会改变她何时可以继续读，但不会阻止你和她聊天。

## 怎么使用

1. 打开「配置」页的「大肥鱼的作息」。
2. 「真实作息」默认开启，使用部署时区的固定时间：睡觉 23:00—08:00，早餐 08:00—08:30，午餐 12:00—13:00，晚餐 18:00—19:00。
3. 不想让她按这套作息停读时，关闭「真实作息」；短休息仍会保留。
4. 在「正在读」可以看到当前是睡觉、用餐、短休息还是其他等待原因。
5. 短休息可以点「结束休息」提前继续；睡觉和用餐期间不能强行阅读。

## 需要注意

- 作息是调度配置，不是模型自报的心情或状态。
- 已经发出的模型请求无法强制撤销，但晚到任务会失效，不能增加已读进度。
- 程序退出期间不阅读，重启后不会补齐离线时间。
- 作息时间固定，不需要逐项设置；时区取部署时区。

## 进一步了解

聊天优先于自主阅读。你正在和她说话时，她不会为了完成阅读机会而打断对话。
