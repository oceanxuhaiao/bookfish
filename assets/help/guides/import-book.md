# 导入一本或多本书

把本地小说交给大肥鱼。导入和阅读是两件事：文件进入书架，不等于她已经读过。

## 怎么使用

1. 打开「书架」，点「＋ 推荐书籍」。
2. 抽屉默认是「本地导入」，按需要选「选择文件（单本或多本）」「选择文件夹」或「导入 ZIP」。
3. 先看清单：能导入的书、不支持的文件、重复或超限的文件都会列出来；不想导入的那几本可以逐本取消。
4. 点「导入所选 N 本」。导入在后台进行，关掉抽屉也会继续；书架会显示进行中的进度入口，可以随时回来查看。
5. 完成后展开「查看详细报告」：进批、入库、失败、取消和未导入的数量与原因都在这里；失败项可以单独重试。
6. 需要的话再点「选择书籍加入阅读顺序」，勾选要排进去的书。默认不选，也不会自动开始读。

在线找书请在抽屉里切到「在线找书」：支持链接获取和按书名/作者获取。

## 导入限制

- 单个文件不超过 100 MiB，一批不超过 1 GiB，最多 100 本。
- 支持 TXT、Markdown、EPUB 和带文字层的 PDF；ZIP 里的隐藏文件、说明文件和不支持的格式不会静默消失，会写进报告。
- 扫描版 PDF（多数页面没有文字层）和 DRM 加密的 EPUB 会被拒绝，并写明原因。
- 文件夹或 ZIP 触发上限时整包拒绝：不会只导入一部分，原压缩包会保留，可以拆小重试。
- EPUB/PDF 的图片和版式不会导入；PDF 需要文字层。

## 失败与恢复

- 失败的书可以单独重试；文件被移动或改名时，会要求重新选择同一个文件，内容不一致会被拒绝。
- 重启宿主或关掉面板后，未完成的批次会保留记录，在书架重新打开即可继续。
- 重复导入不会在书架上创建重复条目；同批其他书失败不影响已经入库的书。
