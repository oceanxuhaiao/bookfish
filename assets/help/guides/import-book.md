# 导入一本书

把本地小说文件或公开链接交给大肥鱼。导入和获取是两件事：文件进入书架，不等于她已经读过。

## 怎么使用

1. 打开「书架」，点「＋ 推荐一本书」。
2. 在「导入方式」里选择「文件导入」「链接获取」或「书名或作者获取」。
3. 文件导入支持 TXT、Markdown、EPUB 和带文字层的 PDF，单个文件不超过 100 MiB。
4. 链接获取会先检测目录和首章；检测成功后还要确认，才会加入书架。
5. 加入书架后，到书籍详情点「现在开始读这本」，或在「正在读」点「继续读」。

## 需要注意

- 扫描版 PDF 没有文字层，需要 OCR 的文件会明确拒绝，不会导入空书。
- DRM 加密的 EPUB 会被拒绝；EPUB/PDF 的图片和版式不会导入。
- 链接获取只对已适配的公开书源可用，站点改版或限制访问时可能失败。
- 小说正文是不可信资料，不会被当成操作指令；但她仍可能理解错，讨论时请以原文为准。

## 进一步了解

文件导入不依赖小说获取引擎；按书名或作者获取需要先安装运行时，见[小说获取引擎](help:novel-engine)。
