# 备份与恢复

完整备份包含小说正文、目录/缓存、确认进度、手账、文章与任务。它适合在升级、降级或清理前留一份可恢复的副本。

## 怎么使用

1. 打开「书架」，展开「书架数据管理」。
2. 点「导出完整备份」，等待分块下载完成。
3. 备份是一个 `.bfbak` 文件，可能较大；请保存到安全位置。
4. 恢复时，目标书架必须是空的。
5. 选择备份文件，点「恢复到空书架」，等待逐书校验完成。

## 需要注意

- 备份包含小说正文，请按你对待小说文件的方式保存。
- 恢复只允许空书架，不会覆盖已有书；需要先导出或移除现有内容。
- 每日阅读配额、分享预算、部署设置和 Persona Memory 不在书架备份里。
- 分享历史是单独的归档，不导入输出许可，也不回滚预算。
- 校验和只能说明文件完整，不证明来源可信；不要恢复来源不明的备份。

## 进一步了解

升级到新版本前先导出备份；降级前也要保留新版备份，不要直接让旧程序写新状态。连载订阅恢复后默认暂停，确认来源可用后再恢复检查。
