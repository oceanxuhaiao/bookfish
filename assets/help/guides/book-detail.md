# 书籍详情与阅读起点

书籍详情把一本书的正文、进度、足迹和读后感放在一起。这里的「阅读正文」是给你自己看的，不会改变她的阅读进度。

## 怎么使用

1. 从「正在读」或「书架」打开一本书的详情。
2. 点「阅读正文」打开你自己的阅读器；它支持目录、翻节、字号和背景。
3. 点「查看阅读足迹」查看这本书的感想和原文依据。
4. 点「现在开始读这本」才会切换她正在读的书。
5. 如果这本书你已经在别处读过前几章，可以用「从某一章开始读」声明起点。

## 需要注意

- 你自己的阅读器和大肥鱼的进度分开；你翻页不会增加她的已读。
- 阅读起点只改变她从哪一章开始，前面的章节不会被记作已读，也不会进入手账或读后感。
- 起点必须在任何阅读发生前声明，她读完第一段后就会锁定。
- 点「移除这本书」会删除正文、进度、手账、读后感和对应分享文本，无法撤销。

## 进一步了解

声明起点后，这本书不会再生成“全书读后感”，因为她没有逐段读过前面的内容。引用和讨论也只能回查她真正读过的范围。
