# 让她自己找书

这是实验功能，默认关闭。开启后，她可以提出具体书名、作者和第一人称理由，再搜索、获取、校验并排队；获取成功不等于读过。

## 怎么使用

1. 打开「配置」页。
2. 开启「让她自己找书（实验功能）」。
3. 选择「找到以后」的方式：自动获取并排队，或找到后告诉你。
4. 需要限制来源时，在「允许自主使用的书源 ID」里填逗号分隔的 ID；留空表示全部已收录书源。
5. 在「书架」的「她想读的」区域查看理由、候选、获取进度和失败原因。

## 需要注意

- 自动模式只接受书名、作者和允许书源都精确匹配的版本，不会接受任意链接。
- 一本自选书成功入架后，在确认读完之前通常不会自主找下一本；排队、暂停、切换和重启都不解除这个承诺。
- 搜索失败、获取失败或校验失败会换另一本不同作品；连续失败会冷却，不会无限重试。
- 不登录、不购买、不绕过访问限制；关闭开关会暂停这条链路。

## 进一步了解

只有你明确删除书，或在「她想读的」里点「放弃这本自选书」，才会结束“读完之前不再找下一本”的承诺。
