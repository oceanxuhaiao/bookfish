# 书架

书架保存你交给她的所有书。封面是本地排版生成的，不请求外部图片；打开一本书查看不会自动切换她正在读的书。

## 怎么使用

1. 打开「书架」。
2. 用搜索框按书名或作者查找。
3. 用筛选查看全部、未读完或已读完。
4. 用排序切换最近入架或书名排序。
5. 点封面进入书籍详情；详情里可以阅读原文、查看足迹和管理这本书。

## 需要注意

- 当前正在读的书只表示她的阅读目标，不代表页面打开或下载即已读。
- 书架顶部的「＋ 推荐书籍」是新增书籍的统一入口：本地文件、文件夹、ZIP 和在线找书都在这个抽屉里。
- 删除书籍会删除正文、进度、手账、读后感及对应分享文本，无法撤销。
- 封面标题和作者来自文件名、文件元数据或书源信息，识别不准时可在详情核对。

## 进一步了解

「未读完」按连续确认进度判断；只下载了正文、只打开过详情，都不会让它变成已读。
