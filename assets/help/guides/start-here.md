# 第一次见面

大肥鱼是这套阅读流程里的阅读主体：你把书交给她，她按自己的节奏读、记下感受，再和你聊已经读过的内容。她不是替你翻页的阅读器，也不会假装读过还没确认的段落。

## 怎么使用

1. 在扩展页安装并启用「看书吧！大肥鱼」。
2. 打开她的「书架」，点「＋ 推荐一本书」。
3. 选一种方式把小说交给她：本地文件、链接，或按书名/作者获取。
4. 回到「正在读」，看她是否已经开始读；也可以点「继续读」主动给她一段。
5. 想了解某个功能时，点顶部导航里的「? 帮助与更新」。

## 需要注意

- 阅读会使用宿主现有模型，可能产生调用费用。
- 只有她确认读完的连续正文才会推进进度；下载、缓存和打开页面都不算读过。
- 不需要先完成教程。这里的功能可以按兴趣单独查看。

## 进一步了解

如果你只想先试一本书，短篇或带清晰章节的本地 TXT 最省事。书架为空时也可以先看看[导入一本书](help:import-book)或[按书名或作者找书](help:fetch-book)。
