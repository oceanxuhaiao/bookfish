# 删除与清理

删除和清空是不可撤销的操作。先确认你要删的是某一本书，还是整个书架；两者影响的范围不同。

## 怎么使用

1. 删除单本：打开书籍详情，点「移除这本书」，确认后删除。
2. 清空书架：到宿主扩展页的存储/数据区域，清除本扩展的书库存储项。
3. 清分享历史：在书架数据管理或对应存储项里清除，保留去重摘要和预算。
4. 清理前先导出完整备份，尤其是你还想保留正文或阅读记录时。

## 需要注意

- 移除一本书会删除该版本的正文、确认进度、阅读手账、读后感及对应分享文本，无法撤销。
- 清空书架会清除全部书籍和阅读记录，但不会清 Persona Memory，也不会改变更新提醒状态。
- 清分享历史只删除分享文本，保留已用的尝试预算和去重摘要。
- 运行期间不要手动删除写锁数据库；需要维护时先停用扩展并退出实例。
- 清理不会自动重新下载或补读；之后需要重新导入或获取。

## 进一步了解

更新提醒状态是独立的安装级 UI 元数据，不在书架里。清空书架、删除单本或重建阅读索引，不会让历史公告重新提醒。
