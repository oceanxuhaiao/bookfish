# 小说获取引擎

按书名或作者搜索、下载和校验需要一个独立的运行时包。扩展包本身不包含这个约 85 MiB 的运行时。

## 怎么使用

1. 打开「配置」页，找到「小说获取引擎」卡片。
2. 有受信下载来源时，点「一键安装小说引擎」。
3. 没有可用下载来源时，点「导入离线运行时包」，选择对应的 ZIP。
4. 安装会依次下载/接收、校验摘要、安全解压、启动自检和原子切换。
5. 安装成功后不需要重启宿主，按书名/作者搜索会自动启用。

## 需要注意

- 首次安装约需 85.8 MiB 下载和 189.4 MiB 磁盘空间。
- 安装失败、取消或宿主关闭不会替换旧版；旧运行时和书架数据会保留。
- 卸载只删除运行时，不删除书架、进度、手账、下载缓存或续传索引。
- 文件导入和链接获取不依赖这个引擎；只有按书名/作者获取需要它。
- 模型没有下载、安装或执行命令的工具；安装只在你点击时发生。

## 进一步了解

运行时包含第三方 so-novel 和 Temurin JRE，按各自许可证分发；来源、版本和校验信息见项目 README 与 THIRD_PARTY_NOTICES。卸载后想再按书名获取，需要重新安装或导入运行时。
