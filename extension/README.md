# BookFish 浏览器桥接扩展（协议 v2）

当前为本机试用版本。用户在书架配置中确认普通模式后，手动及模型自主获取不强制要求安全组件或独立浏览器；仍建议增强保护。普通模式可能携带浏览器登录态，不保证强制网络隔离。正式控制器尚未接入，增强模式保持失败关闭；配对成功不代表隔离验证通过。扩展仍须安装、配对；来源默认逐个授权，也可以在弹窗一次性允许所有网站。不能绕过网站访问控制。自动安装、真实权限对话及浏览器更新流程的完整验收仍待完成。

审核后在独立 Chrome／Edge 配置中手工“加载已解压的扩展程序”，选择本目录。端口和令牌仅来自隔离 BookFish 数据目录；在弹窗填写来源 URL，点授权，或打开“允许所有网站”一次性放开。默认只允许明示授权的精确 origin；允许所有网站时以浏览器的全站授权为准。撤销来源／修改配对设置会取消进行中的传输。Chrome 的主机权限按主机授权，工作线程在每次请求和重定向落地后另做来源检查。

权限为 storage、alarms、本机127.0.0.1桥接及可选 HTTP／HTTPS 来源权限。默认不授予 all_urls；“允许所有网站”只在用户点击后申请 http/https 全站权限，可随时从弹窗或浏览器扩展管理页撤销。无代理、debugger 或 Cookie 导出权限。协议v2要求消费者租约、序号和完成字节数，v1不能混用。HTTPS使用浏览器已有登录态，HTTP不带凭据；不代登录、付费或绕过验证。

重定向会被跟随，落地地址重新做协议、凭据、来源和权限检查（HTTPS 不允许降级到 HTTP）；失败或越界时返回拒绝而不是静默接受。页面最多8MiB、文件最多100MiB、单次上传块最多4MiB，原始字节不转码，失败／超时取消读取。令牌只存本机；不要粘贴到聊天、日志或截图中。

审核状态和尚未覆盖的安全边界见 docs/txt-acquisition/ROUND2-IMPLEMENTATION-REVIEW.md。

## 内置 Bing 搜索来源（扩展 0.65.1）

必需 host_permissions 仅包含本机桥接与 https://cn.bing.com/*，搜索来源随安装授权，无需手动添加。内部允许列表默认启用该精确 HTTPS origin，不自动授权其他 Bing 主机、端口或下载网站。旧版更新可能要求浏览器重新确认新增权限；不绕过确认或浏览器网站访问限制。

弹窗可停用/恢复 Bing 搜索来源。停用保存为 bingSearchEnabled=false，重启/更新不恢复；撤销时中止在途传输。因该权限为安装必需项，弹窗停用仅禁止本扩展派发，浏览器权限仍由扩展管理页控制；权限 API 确认缺失时后台始终拒绝。

## 允许所有网站（0.66.0）

弹窗新增“允许所有网站（不推荐）”。点击后向浏览器申请 `http://*/*` 与 `https://*/*` 可选权限；授权后扩展不再检查逐站来源列表，搜索与下载可直接访问任意 http/https 网站，重定向照常跟随并在落地后复核。撤销按钮会移除全站权限并恢复逐站授权。

代价必须说清：开启后，只要 BookFish 派发请求，扩展就会带着当前浏览器对该网站的登录态访问；不再有“这个网站你从没授权过”这一层拦截。只应从书架配置页进入扩展弹窗操作，不要把令牌发给他人。仍保留的限制：仅 http/https、拒绝账号密码形式的 URL、HTTPS 不降级、内网/回环地址由桥接侧 URL 策略拒绝、文件大小与哈希校验不变。
