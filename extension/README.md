# BookFish 浏览器桥接扩展（Edge / Chrome）

这个扩展让《看书吧！大肥鱼》用**你自己日常使用的 Edge 或 Chrome**去打开资源页、下载 TXT/Markdown 文件，不需要 `--remote-debugging-port`，也不需要重启浏览器。

设计边界：

- 世界（BookFish）只在本机 `127.0.0.1` 上开一个小端口，扩展主动去取任务，网页无法调用这个端口。
- 每次请求都要带配对令牌；令牌只存在扩展本地和 `data/bookfish/txt-acquisition/bridge.json`。
- 扩展只用你已登录的浏览器抓取**你有权访问**的页面；不登录、不付费、不绕过验证码或 DRM。
- 扩展不接管、不关闭、不读取你的其它标签页；每个任务是后台 `fetch`，不弹新标签页。
- 扩展只负责搬运原始字节；判断、补正、导入都由 BookFish 完成。

## 安装（解压加载）

1. 打开 BookFish 设置页，在「现成的 TXT 文件」卡片里打开 **允许获取现成的 TXT 文件** 和 **用 Edge/Chrome 扩展取文件**，保存。端口保持 `0`（即 47823）即可；同一张卡片会显示端口、配对令牌和「复制」按钮。
2. Edge：地址栏输入 `edge://extensions` → 打开左下「开发人员模式」→「加载解压缩的扩展」→ 选择本仓库的 `extension/` 目录。
   Chrome：地址栏输入 `chrome://extensions` → 打开右上「开发者模式」→「加载已解压的扩展程序」→ 选择 `extension/` 目录。
3. 回到设置卡片，点 **复制**（复制的是 `端口 / 令牌`）。
4. 点浏览器工具栏里的 BookFish 图标，把复制到的整段「端口 / 令牌」粘进任意输入框，点「保存并连接」。状态显示「已连接」即可。

Edge 和 Chrome 都是 Chromium，同一份 `extension/` 目录通用。扩展需要 `storage`、`alarms` 权限和 `http://127.0.0.1/*`、`<all_urls>` 的主机权限：前者用于连接桥接，后者用于访问你指定的资源页与下载地址。

## 使用

在 BookFish 里让她想看书时，工具 `bookfish_import_txt` 会自动选择可用的浏览器通道：

- 开了扩展桥接 → 走扩展；
- 只配了调试端口 → 走 CDP；
- 都没配 → 任务失败并提示去设置。

`discover` 扫描资源页、`import` 下载候选、`status` 查任务、`retry` 重试、`repair` 用保留的原件换个编码再导入。

## 安全说明

- 桥接只绑定 `127.0.0.1`，任何请求都要令牌；带 `Origin` 的网页请求会被拒绝（只接受扩展自身）。
- 落地地址会再校验一次：即使页面 302 到内网或云元数据地址，也会被拒绝。
- 单个页面回传上限 8 MiB，单块 4 MiB，原文件仍受 BookFish 的 100 MiB 上限约束。
- 令牌写在数据目录的 `bridge.json` 里，删掉该文件并重启世界会生成新令牌（扩展需要重新填入）。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 弹窗一直「未连接」 | 确认 BookFish 正在运行、设置里已开启扩展桥接、端口一致 |
| 提示「令牌不匹配」 | 重新从 BookFish 面板复制令牌；必要时删除 `bridge.json` 后重启世界再配对 |
| 任务提示 `browser_unavailable` | 扩展没连上或桥接端口被占用；换一个端口并同步扩展设置 |
| 下载返回 `policy_blocked` | 目标地址解析到内网/回环，或被重定向到不允许的地址 |
| 提示 `no_candidates` | 该页面没有 `.txt`/`.md` 下载链接，换一个资源页 |
